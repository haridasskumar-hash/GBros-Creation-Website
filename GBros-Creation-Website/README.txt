G-Bros. Creation — Vietnamese / English Website

Unzip this download. Upload the CONTENTS of GBros-Creation-Website to your GitHub repository, keeping the folders intact. Do not upload the ZIP itself.

The root of your repository should contain:
index.html       Vietnamese homepage (default)
en/index.html    English homepage
style.css        Shared design and responsive layout
assets/          Logo and photographs

For GitHub Pages, publish the branch containing these files from its root directory. No build command or dependency installation is needed.

You can also open index.html on your computer to preview the website.
Relative links support both a custom domain and a GitHub Pages project subfolder.

To edit text, update index.html and en/index.html separately. To change photographs, replace the corresponding images in assets, retaining their filenames, or update their references in both HTML files.

Contact buttons open phone, Facebook, Flickr and Google Maps links. This website has no contact-form backend or admin editor.

Your currently hosted ChatGPT Site has not been changed by this export.
