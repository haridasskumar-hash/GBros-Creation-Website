# G-Bros Creation — Food Photography
Upload-ready static article. No installation, build step, external fonts or JavaScript required.

## Upload to the existing GitHub Pages website
1. In the GBros-Creation-Website repository, create a folder named food-photography.
2. Upload index.html and the complete assets folder into it, keeping their structure.
3. Commit to the branch used by GitHub Pages.
4. The article will be available at:
   https://haridasskumar-hash.github.io/GBros-Creation-Website/food-photography/
5. Add a link from your homepage or blog navigation to ./food-photography/.

The ZIP already contains the food-photography directory. Extract it, then upload the extracted directory contents through GitHub or copy the directory into a repository checkout. Do not upload only the ZIP file: GitHub Pages will not unpack it.

## Preview
Open index.html locally. All images and styles work offline. Website, social, map and telephone links lead to the real destinations.

## Changing the destination
If you publish under another domain or folder, update the canonical link, og:url, og:image, and the URL/image/logo fields in the JSON-LD. The current values deliberately match the upload location above.

## Content and assets
Vietnamese is primary; the full supplied English article follows on the same page. Language links jump between sections, so both versions remain readable without scripts. Original article wording was retained; the header summary and image captions are editorial additions.
All six photographs and the logo come from the supplied project files. Sources were left unchanged. Image copies are resized and JPEG optimized, with smaller responsive variants. assets-manifest.json maps them to the originals.
Contact details and branding were matched against the supplied website. No unverified email address was added.
